kpiadx.kpi
==========

CRI ミドルウェア社の ADX フォーマット音声ファイルを再生する KbMedia
Player 用プラグインです．対応する拡張子は .adx, .aax, .afs です．

ADX フォーマットのいわゆるバージョン 3 と 4 に対応します。エンコードタイ
プが「3: リニア」以外の形式は、手元にデータがないため、実際のゲームのデー
タで正しく再生できるかどうかはわかりません。AHX および暗号化 ADX には対
応していません。

3 チャンネル以上の ADX も再生できます。

AAX (ADX をいくつかつないだもの) は 1 曲として再生します。ループの印が付
いたところをループします。

AFS アーカイブは 1 ファイル複数曲として開くことができます。AFS にファイ
ル名の表があれば、そのファイル名を曲名とします。曲名ではなくファイル名な
ので、拡張子も付いたままです。ファイルの日時が入っていれば、詳細情報の
AFS_FileDate に出します。

ADX の先頭にはループ位置を揃えるための無音が足されていることがあります。
これは再生せずに読み飛ばします。曲の長さとループ位置もこの分を差し引いた
ものになります。

v2.0 から瞬時シークに対応しています。曲の途中にシークした直後は、ADX の
デコードに必要な直前の値が分からないため、ごく短い間だけ元の音と少し違う
ことがあります。

v2.0 では ADX のスケールを正しく解釈するため、v1 系にあったマスターボリ
ュームの設定は不要となっています。また曲長計算のためのループ回数も本体の
設定に従います。kpiadx.ini は使いません。

詳細情報には次の項目を出します。

  ADX_EncodingType       エンコードタイプ
  ADX_Version            ヘッダのバージョン
  ADX_BlockSize          ブロックの大きさ (バイト)
  ADX_SampleBitDepth     1 サンプルのビット数
  ADX_HighPassFrequency  ハイパスフィルタの周波数
  ADX_TotalSamples       曲のサンプル数 (先頭の無音を除く)
  ADX_InsertedSamples    先頭に足された無音のサンプル数
  ADX_LoopCount          ヘッダにあるループ回数
  ADX_IsLooped           ループするかどうか
  ADX_LoopStartSample    ループ開始位置 (サンプル)
  ADX_LoopEndSample      ループ終了位置 (サンプル)
  ADX_Flags              暗号化されている場合のみ
  AAX_Segments           AAX のセグメント数
  AFS_FileDate           AFS のファイル名表にある日時

ADX_InsertedSamples と ADX_LoopCount は、ヘッダにループ情報の欄がある
ADX のときだけ出します。

Visual Studio 2026 でビルドしており、Visual C++ のランタイムを使います。
プラグインが KbMedia Player のプラグイン設定で failed to load plug-in と
言われて ADX ファイルを開けない場合は、最新の「Visual C++ 再頒布可能パッ
ケージ」をインストールしてから試してみてください。

最新の Microsoft Visual C++ 再頒布可能パッケージ
https://learn.microsoft.com/ja-jp/cpp/windows/latest-supported-vc-redist


著作権とか
----------

ADX フォーマットについて以下のサイトを参考にしました．
http://ku-www.ss.titech.ac.jp/~yatsushi/
http://www.geocities.co.jp/Playtown/2004/
http://www.smallnews.net/azuco/

v2.0 では以下の資料を参照しています。
https://en.wikipedia.org/wiki/ADX_(file_format)
https://azuco.sakura.ne.jp/column/ag_adx/cri.html
https://github.com/Thealexbarney/VGAudio/tree/master/src/VGAudio/Codecs/CriAdx

AAX と AFS のファイル名表、ADX のヘッダの欄の意味は、以下も参照しています。
https://github.com/vgmstream/vgmstream
https://github.com/Thealexbarney/VGAudio/tree/master/src/VGAudio/Containers/Adx

ADX フォーマットの解析およびデコーダの実装は，Autch が上記サイトを参考に
して行ったものです．このプラグインについて CRI ミドルウェア社や各種ソフ
トの発売元および上記サイトにサポートを求めてはいけません．

各ソフトから抽出したデータはその著作権者の著作物です．これら著作物を私的
利用の範囲を超えて，権利者の許可なく利用することはできません．

・AAX に対応
